## 🛠 Tech Stack & Components

- **OS:** Arch Linux
- **Window Manager:** Hyprland
- **Bar / Widgets:**  Quickshell
- **Terminal:** Kitty 
- **Shell:** bash
- **Text Editor:** vim
- **Font:** JetBrainsMono Nerd Font
- **Application Launcher:** Rofi
